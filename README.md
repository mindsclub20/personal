# Shyam — Personal Portfolio

A responsive personal website for sharing learning interests and projects in progress.

## Built with
- Semantic HTML
- CSS design tokens, responsive layouts, and reduced-motion support
- Vanilla JavaScript for accessible mobile navigation

## Run locally
Open `index.html` in a browser, or run a static server from this folder:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Content notes
- Project cards are clearly marked as concepts or learning work.
- No private phone number, home address, or personal email is published.
- Replace or remove project descriptions as work evolves.
- The GitHub link points to the public profile at https://github.com/mindsclub20.

## Deployment
Designed for static hosting. It can be connected to Vercel with this GitHub repository.
