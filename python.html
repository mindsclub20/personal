What works?
Python's standard library and many pure-Python packages work. This is a browser-based CPython runtime, not a remote server. It cannot directly control physical robots or access your computer's files.
Safety & privacy
Only run code you understand. This page is not a secure sandbox for untrusted code. Avoid secrets, passwords, and private data in programs.

Powered by Pyodide (Python compiled to WebAssembly). An internet connection is required the first time to load the Python runtime.
