🧠 Boards & firmware

ESP32 is the priority board, with Arduino Uno and RP2040/Pico templates. Full C++ compilation depends on the external firmware simulator; this page does not pretend to compile arbitrary code.

📡 Real ESP32 execution

Use the official ESP32 simulator to compile and execute supported firmware, inspect serial output and test supported Wi-Fi workflows.

🔒 Project privacy

This lab uses the existing Shyam Tools owner login. Saved projects stay in this browser's local storage; they are not uploaded to a server or shared automatically.

Simulation honesty: the canvas currently models component placement, wires and a limited LED/serial demo. It is not yet a full electrical simulator or a local ESP32 firmware emulator. The “Open real simulator” button takes you to Wokwi for genuine supported firmware execution while VisualRobotics is developed further.
