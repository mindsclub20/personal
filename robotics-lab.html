🧪 How to use it

Add components, drag them around, and connect their pins. Load the LED demo, edit the sketch, then run the simplified simulation to see output in the LED and serial monitor.

🛠️ What this beta can and can't do

This is a browser-based learning prototype. It demonstrates basic component placement, wires, and a limited LED sketch runner; it does not compile arbitrary Arduino C++ or emulate real electrical behavior/hardware.
